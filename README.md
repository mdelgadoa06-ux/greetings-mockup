# Greetings · Mockup para el pitch

Plataforma SaaS que reduce la rotación en empresas operativas frontline (peluquerías, autolavados, talleres) cruzando clima laboral con productividad real.

## Ver el mockup

**👉 [Abrir el mockup en el navegador](https://mdelgadoa06-ux.github.io/greetings-mockup/)**

También puedes descargar [`greetings-mockup.html`](greetings-mockup.html) y abrirlo con doble clic en Chrome o Edge (funciona sin internet).

Atajos: `→` avanza · `1` `2` `3` saltan a cada módulo · `0` vuelve al inicio · `?` muestra la ayuda.
